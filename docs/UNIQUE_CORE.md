# The Unique Core of Disha

This is what no other open OSINT / AI intelligence platform currently offers with the same rigor:

1. **Immutable, hash-chained Evidence Ledger**  
   Every observation, policy decision, model suggestion, and human judgment is recorded as a cryptographically linked event.

2. **Mandatory Verification States**  
   Models can only produce PREDICTED or INFERRED. Elevation to VERIFIED requires evidence + policy + human review.

3. **Governed Adapter Bus**  
   The only legal way to talk to the outside world. Every adapter must emit EvidenceEvents. High-risk actions are proposal-only by default.

4. **Executable Constitution**  
   Policy is not documentation — it is enforced before execution.

5. **Human Review as Final Authority**  
   No model or agent can become invisible authority.

---

These five properties together create a system that is **reconstructible under adversarial scrutiny**.

That is the product.
